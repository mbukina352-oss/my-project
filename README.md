# Бот планировок TrendAgent

Пишете в Telegram `Джойс 35млн 60м2`, бот находит в TrendAgent (Москва) подходящие
квартиры и присылает PDF с планировками. На каждой странице стоят ваш логотип, ФИО,
телефон, e-mail, Telegram и агентство.

Примеры запросов:

| Запрос | Что ищет |
|---|---|
| `Джойс 35млн 60м2` | ЖК «Джойс», до ~35 млн, около 60 м² |
| `Level Мичуринский 2к 25 млн` | двухкомнатные до ~25 млн |
| `Шагал студия 30м2` | студии около 30 м² |

По умолчанию бот присылает 3 варианта, ближайших к запросу. Допуск ±10% по площади,
по цене не дороже чем на 10%. Всё это меняется в `.env`.

**Запасной режим.** Можно прислать боту планировку картинкой или PDF и в подписи указать
`Джойс 35млн 60м2`. Бот оформит её в ваш фирменный PDF, в TrendAgent он при этом не заходит.

## Бесплатный запуск на своём компьютере (Windows)

Бот работает, пока включён компьютер и открыто чёрное окно бота. Если компьютер
выключен, бот не отвечает, а после включения снова запустите `start.bat`.

### Шаг 1. Создать бота в Telegram (2 минуты)
1. Откройте в Telegram **@BotFather** и нажмите **Запустить / Start**.
2. Отправьте `/newbot`.
3. Он спросит имя: напишите любое, например `Мои планировки`.
4. Потом адрес: он должен заканчиваться на `bot`, например `planirovki_ivanova_bot`.
5. Придёт сообщение с **токеном** (строка вида `7123456789:AAH...`). Скопируйте её
   и никому не показывайте.

### Шаг 2. Установить Python (5 минут)
1. Откройте https://www.python.org/downloads/ и нажмите жёлтую кнопку **Download Python**.
2. Запустите скачанный файл.
3. **Внизу окна поставьте галочку «Add python.exe to PATH»**. Это обязательно!
4. Нажмите **Install Now**, дождитесь окончания и нажмите **Close**.

### Шаг 3. Скачать бота
1. Откройте ссылку (перед этим войдите в свой аккаунт GitHub):
   https://github.com/mbukina352-oss/my-project/archive/refs/heads/claude/trend-agent-planning-umwdo0.zip
2. Скачается ZIP-архив. Нажмите на него правой кнопкой → **Извлечь всё…** → **Извлечь**.
3. Появится папка `my-project-...`. Можно перенести её, например, на Рабочий стол.

### Шаг 4. Логотип
Положите файл логотипа в папку `assets` внутри папки бота и назовите его `logo.png`.

### Шаг 5. Первый запуск и ваши данные
1. В папке бота дважды щёлкните **`start.bat`**. Если Windows покажет синее окно
   «Система Windows защитила ваш компьютер», нажмите **Подробнее** → **Выполнить в любом случае**.
2. Первый раз бот 3–5 минут всё устанавливает. Потом откроется **Блокнот** с настройками.
3. Впишите после знака `=` (без пробелов вокруг `=`):
   - `BOT_TOKEN=` токен из шага 1;
   - `AGENT_NAME=`, `AGENT_PHONE=`, `AGENT_EMAIL=`, `AGENT_AGENCY=`, `AGENT_TELEGRAM=` ваши данные;
   - `TA_LOGIN=` и `TA_PASSWORD=` логин (телефон) и пароль от TrendAgent.
4. Нажмите **Ctrl+S**, чтобы сохранить, и закройте Блокнот.

### Шаг 6. Запуск
1. Снова дважды щёлкните **`start.bat`**. Появится надпись «Бот запущен». Окно **не закрывайте**,
   его можно свернуть.
2. Найдите своего бота в Telegram по адресу из шага 1 и нажмите **Запустить**.
3. Отправьте `/id`. Бот пришлёт число, это ваш Telegram ID.

### Шаг 7. Закрыть бота от посторонних
1. Закройте чёрное окно бота.
2. В папке бота откройте файл `.env` (правой кнопкой → **Открыть с помощью** → **Блокнот**).
3. В строку `ALLOWED_USER_IDS=` впишите число из `/id`, сохраните (**Ctrl+S**).
4. Снова запустите `start.bat`. Готово: пишите боту `Джойс 35млн 60м2`.

**Чтобы компьютер не засыпал:** Пуск → Параметры → Система → Питание →
«Переводить в спящий режим» → **Никогда** (при питании от сети).

**На Mac** всё так же, только вместо `start.bat` запускайте `start.command`
(первый раз: правой кнопкой → **Открыть** → **Открыть**).

## Запуск на сервере (платно, работает круглосуточно)

Любой VPS на Ubuntu с 2 ГБ памяти (примерно 300–600 ₽ в месяц):

```bash
curl -fsSL https://get.docker.com | sh
git clone https://github.com/mbukina352-oss/my-project.git && cd my-project
cp .env.example .env && nano .env
docker compose up -d --build
```

## Как это устроено

- `bot/query.py` разбирает запрос (ЖК, цена, площадь, комнаты);
- `bot/trendagent.py` через браузер (Playwright) входит в ваш кабинет TrendAgent и собирает
  квартиры и ссылки на планировки;
- `bot/matching.py` выбирает варианты, ближайшие к запросу;
- `bot/pdf.py` собирает PDF с вашими данными;
- `bot/main.py` содержит самого Telegram-бота.

Открытого API у TrendAgent нет, поэтому бот работает через ваш личный кабинет, как обычный
браузер. Адреса страниц и селекторы формы входа вынесены в `.env` (`TA_*`), и если сайт
изменится, код править не придётся.
